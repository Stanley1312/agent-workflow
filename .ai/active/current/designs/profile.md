# Screen Analysis: Profile

## Source
`requirements/mockups/p1_profile_screen.png`

## Layout Map
1. Global top navigation
   - Brand, nav links, search, Post action, notification, user avatar
2. Profile hero card
   - Purple initials avatar
   - User name, location/member-since line
   - Star rating summary with review count
   - Badges: Top Rated, Fast Responder, Verified
   - Edit profile button when viewing own profile
3. Stats cards
   - Completed deals
   - Average rating
   - Response rate
4. Reviews panel
   - Header with total count
   - Large rating summary and stars
   - Horizontal rating distribution bars
   - Individual review rows with reviewer avatar, name, text, star rating, date
   - Show all reviews button

## Visual Notes
- Spacious white cards on warm off-white background.
- Purple avatar and tiny brand accents; orange/yellow ratings.
- Stats cards are large, minimal, and typography-led.

## Interaction Notes
- Profile tabs/sections should become active where represented.
- Empty listings/reviews states must preserve layout.
- Review submission controls, if rendered, validate rating/content and update aggregate.
