# Screen Analysis: Sign In

## Source
`requirements/mockups/p1_signin_screen.png`

## Layout Map
1. Minimal top navigation
   - Brand left
   - New here? prompt and Sign up button right
2. Left marketing panel
   - Purple full-height area with dot pattern and oversized translucent arc graphics
   - Small MatchMarket brand mark
   - Large headline: Welcome back. Your matches are waiting.
   - Supporting copy
   - Recent match testimonial card
3. Right auth area
   - Centered white auth card
   - Segmented tabs: Sign up and Sign in, Sign in active
   - Title and subtitle
   - Username/email field
   - Password field with forgot password link and visibility toggle
   - Remember checkbox
   - Primary Sign in button
   - Create account secondary link
   - Security footnote

## Visual Notes
- Auth pages split 50/50 desktop layout.
- Purple gradient/pattern marketing panel is the dominant brand moment.
- Auth card uses soft shadow, rounded corners, and lavender primary button.

## Interaction Notes
- Missing/invalid credentials show field or form errors.
- Visibility toggle changes password input type.
- Sign up links navigate to registration.
- Successful sign-in returns user to relevant marketplace state.
