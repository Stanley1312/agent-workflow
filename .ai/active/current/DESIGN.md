# DESIGN: Marketplace App Phase 1

> Generated by Architect from `requirements/mockups/`. Implementor must follow this file strictly for all UI waves.

## Overview
MatchMarket is a clean local marketplace interface with a warm off-white workspace, white rounded cards, compact dashboard navigation, black primary marketplace actions, and purple brand/auth accents. The product experience should feel fast, practical, and trustworthy while preserving the mockups' visible layout hierarchy across browse, detail, profile, sign-in, and sign-up screens.

## Components

### Global Navigation
- **Shape**: Full-width 48px-high top bar with square brand icon and compact links.
- **Background**: `surface`.
- **Border**: 1px bottom `border`.
- **States**: Active nav link uses subtle underline/pill; Post uses purple filled pill; avatar is circular.
- **Notes**: Keep navigation visible on browse, detail, and profile screens.

### Listing Card
- **Shape**: `md` radius with overflow-hidden image area.
- **Background**: `surface`.
- **Border**: 1px `border`.
- **States**: Hover may lift with `shadow-sm`; Match button remains dark.
- **Notes**: Image must preserve aspect ratio and use stable fallback on missing asset.

### Filter Toolbar
- **Shape**: Rounded controls with small text.
- **Background**: Parent card `surface`, controls `surface-alt`.
- **Border**: 1px `border`.
- **States**: Active filters use purple text or subtle purple tint; Reset is text-only.
- **Notes**: Must include visible category, price, distance, condition, sort, reset, tabs, and save-search controls.

### Detail Summary Card
- **Shape**: `lg` radius side card.
- **Background**: `surface`.
- **Border**: 1px `border`.
- **States**: Primary Start a deal button is black; Message/Save are secondary icon actions.
- **Notes**: Contains price, seller, listing facts, CTAs, and proposal card.

### Auth Card
- **Shape**: `lg` radius card centered in right pane.
- **Background**: `surface`.
- **Border**: 1px `border`.
- **States**: Active tab has purple underline; primary button lavender with darker hover.
- **Notes**: All form fields require labels, helper/error text, and accessible invalid state.

### Profile Review Panel
- **Shape**: `lg` radius content panel.
- **Background**: `surface`.
- **Border**: 1px `border`.
- **States**: Review tab/button active states use purple; star ratings use warning.
- **Notes**: Rating bars must remain stable for zero-review profiles.

## Do's and Don'ts

1. Do preserve the white-card-on-warm-background marketplace shell from the mockups.
2. Do use purple primarily for brand, Post, auth, active tabs, and proposal accents.
3. Do use black/dark primary CTAs for marketplace actions like Match and Start a deal.
4. Do keep listing image cards large and evenly cropped.
5. Do provide keyboard focus states on nav links, form controls, filter controls, and card actions.
6. Do include empty and fallback states without collapsing card/panel layouts.
7. Don't introduce payment, checkout, messaging inbox, or shipping UI beyond safe unavailable states.
8. Don't use generic gray default form styling when mockups show compact labeled fields and soft panels.
9. Don't create wave-numbered test file names.
10. Don't let auth pages lose the split purple marketing panel on desktop.
